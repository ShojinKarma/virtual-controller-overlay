# Virtual Controller Overlay 🎮 (ENG / ESP)

Transparent and customizable on-screen controller overlay designed mostly for **scrcpy** users. It maps gamepads, triggers, and joysticks into virtual click inputs.

*(Scroll down for Spanish / Baja para la versión en español)*

## 🇬🇧 English

### 🚀 Download (.exe)
You can download the ready-to-use `.exe` (both ENG and ESP versions) from the **[Releases](../../releases)** tab.
